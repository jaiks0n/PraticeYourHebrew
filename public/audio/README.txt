Ajoutez vos fichiers audio ici (MP3 ou MP4), nommés selon l'id de la carte :

  general/1.mp3 ou general/1.mp4  → vocabulary.ts id "1"
  dev-interview/42.mp3 → vocabulary-dev-interview.ts id "42"
  conjugation/5.mp3    → conjugation-present.ts id "5"

Après git push, le bouton "Écouter" jouera l'audio sur le site.
